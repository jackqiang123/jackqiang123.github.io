🥕 保卫萝卜

怪物们要来吃萝卜啦！在草地上放炮塔，守住最后一波进攻 · Carrot Defense

🪙 金币 0
🥕 萝卜生命 10
🌊 波次 0 / 15
⭐ 分数 0
🏆 最高 0
👾 剩余怪物 0

玩法：点上方炮塔卡片选中，再点草地空格放下（小路和萝卜的位置不能放）。怪物沿小路走向萝卜，炮塔会自动攻击。
炮塔：🍼 瓶子炮 — 便宜射速快；☀️ 太阳花 — 范围伤害；❄️ 冰冻星 — 减速怪物；⚡ 闪电塔 — 高伤远程。点已放的炮塔可以升级（最高3级）或出售。
技巧：弯道处放太阳花/冰冻收益最高；闪电塔守直线；提前点“开始下一波”有金币奖励。守住 15 波就赢啦！
快捷键：1-4 选塔 · 空格 开波 · P 暂停 · F 倍速 · Esc 关面板。鼠标悬停可预览射程（红色=放不了）。
v3 卡通角色版：怪物、萝卜、炮塔全部换成手绘卡通角色——绿团子、橙色快跑、紫色坦克和红魔王 Boss 各有各的样子，萝卜会盯着靠近的怪物看、被咬还会掉眼泪；炮塔信息面板改为棋盘上的悬浮层，打开时棋盘不再被顶走；每波守住会有醒目的结算横幅。
平衡（沿用 v2）：太阳/闪电/冰冻已加强、后期血量曲线放缓，不再只有堆瓶子一条路。

# 🥕 保卫萝卜 · Carrot Defense

一个纯单文件的塔防小游戏，仿《保卫萝卜》玩法，托管在 GitHub Pages 上。

**在线玩：https://jackqiang123.github.io/**

## 玩法
- 点炮塔卡片选中，再点草地空格放置（小路不能放）
- 炮塔：🍼 瓶子炮（快射速）/ ☀️ 太阳花（范围）/ ❄️ 冰冻星（减速）/ ⚡ 闪电塔（高伤远程）
- 点已放置的炮塔可升级（最高 3 级）或出售
- 怪物沿小路吃萝卜，萝卜 10 点生命，守住 15 波获胜

## 技术
- 单个 `index.html`，原生 Canvas + JavaScript，零依赖
- GitHub Pages 直接托管 `main` 分支根目录
